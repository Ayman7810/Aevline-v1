# 🛍️ Aevline – Complete E-Commerce Platform

## 🌟 Overview  
**Aevline** is a fully integrated e-commerce platform with a user-friendly dashboard, designed to offer a seamless shopping experience. The platform includes:

- **Home Page** – Showcases featured and latest products.  
- **User Registration & Login Pages** – Secure access for users.  
- **Forgot Password Page** – Enables password recovery.  
- **Product Details Page** – Displays individual product information.  
- **All Products Page with Filtering** – Products are categorized into:  
  - **Main Category & Subcategory**  
  - **Filter by Type, Brand, or Price**  
- **Ratings & Customer Reviews** – Each product has a review system.  
- **Shopping Cart** – Users can modify quantities and apply **discount coupons**.  

## 🔑 User Dashboard Features  
- **Statistics Section** – Tracks user activity.  
- **Order Management** – View & manage all orders.  
- **Wishlist** – Save favorite products.  
- **Address Management** – Add and edit shipping addresses.  
- **Personal Profile** – Update personal data easily.  

## 🛠️ Admin Dashboard Features  
- **Analytics & Reports** – Track sales and user activity.  
- **Order & Product Management** – Modify orders and products.  
- **Add New Products & Brands** – Expand the product catalog.  
- **Category Management** – Create main & subcategories.  
- **Discount Coupons** – Manage promotional codes for products.  

## 🚀 Technologies Used  
This platform is built using modern web technologies:  
- **React** – Frontend development.  
- **Redux** – State management.  
- **MongoDB** – Database management.  
- **Node.js API** – Backend services.
